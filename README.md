## 📖 项目简介

这是一个**开箱即用的个人导航主页**，整个项目只有一个 `index.html` 文件。

- 🎯 **为留学生 / 重度网络用户设计**：收录海外 AI、国产 AI、全球顶尖公司、流媒体、网络工具等 **10 大分区、130+ 精选站点**
- ⚡ **零依赖零构建**：无需 Node.js、无需 npm install，浏览器双击即用
- 🎨 **深色玻璃拟态风格**：渐变标题、卡片悬浮动效、自动加载各站点真实 favicon

## ✨ 功能特性

| 功能 | 说明 |
|---|---|
| 🔍 **实时搜索** | 顶部搜索框，支持按名称 / 域名关键词即时过滤，分区标题自动隐藏 |
| ⭐ **常用置顶** | 开关打开后按点击次数自动排序，越常用越靠前，带 ⭐ 角标 |
| 💾 **本地持久化** | 点击记录存于 `localStorage`，关浏览器 / 重启电脑不丢失 |
| 🖼️ **自动图标** | 通过 Google favicon 服务加载真实站点图标，失败自动回退 emoji |
| 📱 **响应式布局** | CSS Grid 自适应，手机 / 平板 / 桌面均有良好体验 |
| 🌓 **深色主题** | 护眼深色渐变背景，长时间使用不刺眼 |
| 📊 **动态统计** | 顶部统计条自动计算分区数与站点总数 |
